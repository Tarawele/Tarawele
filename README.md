Мне важно, чтобы разработчик прочитал документ и сразу понял, что нужно сделать. Сначала я разбираюсь в контексте и ограничениях, а потом предлагаю решение.

Провожу интервью со стейкхолдерами, моделирую процессы в BPMN, пишу BRD и SRS, разбиваю задачи на User Stories с чёткими критериями приёмки. Проектирую контракты API в OpenAPI и проверяю, чтобы все сценарии были покрыты тест-кейсами.
